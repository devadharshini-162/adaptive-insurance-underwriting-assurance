# Report Figure Placement Guide

These are vector SVG figures sized for a Word document page width. Insert them
at approximately 15–16 cm wide and retain their captions.

| Report section | Figure | Suggested caption |
|---|---|---|
| 2.4 System Architecture | `detailed-system-architecture.svg` | Figure 1. Detailed architecture of the Adaptive Insurance Submission and Underwriting Assurance System. |
| 2.5 Flowchart | `detailed-submission-flowchart.svg` | Figure 2. Detailed customer submission and underwriter-review lifecycle. |
| 3.2 Module Description | `module-overview.svg` | Figure 3. Major functional modules of the implemented system. |

For Section 4.1, use screenshots captured from the live local application—not
generated images. Recommended screenshots are: customer product selection,
saved draft dashboard, underwriter active-review queue, and concise issue-review
workspace.
